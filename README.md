# Tic-Tac-Toe Game in C

This is my introductory programming project: a command-line Tic-Tac-Toe game developed using basic C. Players make moves by inputting grid coordinates (such as 1,1 or 1,2), and the system automatically updates the position with a 1 or 0. The game automatically handles turn transitions and terminates upon detecting a win condition or a draw.
